AkiliOne Tech Academy

Course: Web Development — Frontend

This is a hands-on, beginner-friendly course covering HTML, CSS, JavaScript, Bootstrap, and Git & GitHub — everything needed to build and ship a real webpage from scratch.

Over the course, We build small interactive pages for every topic, then bring it all together in this capstone project: a personal landing page connected to a live GitHub repository.

What I Learned

HTML

Structuring a page with semantic tags, forms, links, images, lists and tables.

CSS

Selectors, the box model, colors and typography, flexbox, and responsive design.

JavaScript

Variables, operators, conditionals, loops, functions, and manipulating the DOM.

Bootstrap

Containers, the grid system, rows and columns, utilities, and ready-made components.

Git & GitHub

Tracking changes with commits, branching, and pushing a project to a real GitHub repository.

This project

Putting every lab above into one working page — my capstone submission.
